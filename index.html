💡 實用乘車票卡與機場快線

  • Tokyo subway ticket: 依天數計算（24/48/72小時），可無限次搭乘東京 Metro 與都營地下鐵全線。
  • Suica (西瓜卡): 類似台灣的悠遊卡，儲值後直接感應進站，亦可用於便利商店與自動販賣機購物。
  • 桃園機場 (TPE) - 機場捷運: 由台北車站出發搭乘直達車，最快約 35 分鐘可抵達第二航廈。
  • 成田機場 (NRT) - N'EX 成田特快: JR 東日本推出的舒適對號快車，直達東京、澀谷、新宿、橫濱等大站。
  • 羽田機場 (HND) - 東京單軌電車: 出關後直接搭乘，最快 13 分鐘直達「濱松町站」即可輕鬆轉乘 JR 山手線。

🍱美食篇

築地場外市場

📍 推薦度：⭐⭐⭐⭐⭐

特色必吃

雖然築地批發市場已搬遷至豐洲，但場外市場依然熱鬧！這裡有最鮮美海鮮丼、現烤和牛串、玉子燒等各式街頭美食。

推薦店鋪

  • 丸武玉子燒：香甜多汁的現做玉子燒（僅需約150~200日圓）。
  • 築地虎杖：招牌海鮮鮮魚飯、海膽三吃。

炸牛元村 (Gyukatsu Motomura)

📍 推薦度：⭐⭐⭐⭐⭐

特色必吃

超人氣連鎖炸牛排！外皮裹上極薄麵衣炸至三分熟，內裡呈現誘人粉紅色。桌上附有個人石板，可自行加熱調整熟度。

分店資訊

  • 澀谷店/新宿店/上野店：皆位在鬧區，建議避開正餐尖峰時間（排隊約30~60分鐘）。

AFURI 阿夫利拉麵

📍 推薦度：⭐⭐⭐⭐

特色必吃

不同於傳統濃厚豚骨拉麵，AFURI 以「柚子鹽拉麵」聞名。清澈的雞骨淡麗系湯頭加入天然柚子汁，微酸清爽不膩口，炙燒叉燒香氣十足。

推薦點法

  • 柚子鹽拉麵 (Yuzu Shio)：初訪必點。
  • 柚子露沾麵：冷麵條搭配微酸微辣的熱沾醬，夏天絕配。

💰 退稅免稅 (Tax-Free) 小技巧

  • 免稅門檻：同一天在同一家設有免稅服務的店鋪，消費滿 5,000 日圓（不含稅）以上即可辦理。
  • 攜帶證件：結帳時必須出示「本人護照正本」（需有入境蓋章/上陸許可貼紙），護照影本不可辦理。
  • 特殊包裝：免稅購入的消耗品（藥妝、食品、化妝品）會被裝入專用免稅袋封口，在離開日本前切勿拆封。

🧳行前準備

📋 出發前檢查清單 (Checklist)

🔹 必備證件與文件

1. 護照正本（有效期限需六個月以上）
2. 來回機票電子憑證
3. 飯店訂房確認紀錄
4. 役男短期出境證明（19~36歲男性未服兵役者）
5. 註冊填寫 Visit Japan Web (VJW) 取得入境與海關 QR Code

🔹 網路與金流

1. 購買實體網路卡或 eSIM
2. 日圓現金（部分路邊攤或小店不支援刷卡）
3. 信用卡與金融卡(建議多備幾張不同發卡公司的)
4. 手機 iPhone 可先行綁定數位 Suica/PASMO 票卡

🔹 生活常識與電壓

1. 日本電壓為 100V，插頭形狀與台灣相同雙平腳，不需帶轉接頭。
2. 行動電源需放隨身行李攜帶上機，不可托運。
3. 景點門票建議提早購買，以免現場等候時間過長。
4. 日本全面推行靠左行走（與台灣相反，手扶梯也請注意當地習慣）。
